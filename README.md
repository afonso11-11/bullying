# Bullying em escolas públicas e privadas do Brasil

Apresentação do projeto de pesquisa (FECAP, 2026), com dados extraídos de quatro artigos científicos.

- `index.html`: apresentação (abre direto no navegador; setas do teclado para navegar, F para tela cheia)
- `apresentacao_bullying.pdf`: a mesma apresentação em PDF
- `dados/dados_extraidos_pdfs.csv`: números extraídos dos artigos, com a página de origem
- `codigo/graficos_dados_reais.R`: código em R que gera os gráficos
- `graficos/` e `graficos_escuro/`: gráficos em fundo claro e escuro

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub (por exemplo, `bullying-fecap`).
2. Envie **o conteúdo desta pasta** para a raiz do repositório (Add file > Upload files), de modo que o `index.html` fique na raiz e não dentro de outra pasta.
3. Em Settings > Pages, em "Build and deployment", escolha "Deploy from a branch", branch `main` e pasta `/ (root)`, e clique em Save.
4. Após 1 a 2 minutos, o site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.
